# Story 6.2: Apply Design to Settings Screen

## Status
Draft

## Story
**As a** developer,  
**I want to** apply iOS Settings-style design to the Settings screen,  
**so that** it matches the polished Lovable design specification

## Acceptance Criteria
1. Settings screen uses iOS grouped table view style:
   - Background: Light gray (#F2F2F7)
   - Cells: White with 1px separator lines
   - Section headers: All caps, 13px, gray (#6E6E73)
2. Navigation bar styled: Back button (←) with proper spacing
3. Time picker styled to match iOS native time picker appearance
4. Disclosure indicators: Right-pointing chevron (>) for tappable rows
5. Toggle switch (if workflow mode toggle added): iOS-style, blue when on
6. Sign Out button: Red text, centered, styled as destructive action
7. All spacing, typography, and colors follow design system from Story 6.1
8. Coordinate with Epic 3, Story 3.1 implementation (apply design as screen is built, or update after)

**Design Details:**
- **iOS Settings Style**: Grouped table view
- **Background**: Light gray (#F2F2F7) - `colors.surface`
- **Cells**: White (`colors.background`) with 1px separator lines
- **Section Headers**: All caps, 13px (`typography.caption`), gray (#6E6E73 - `colors.textSecondary`)
- **Disclosure Indicators**: Right-pointing chevron (>) - `colors.textSecondary`
- **Toggle Switch**: iOS-style, blue when on (`colors.primary` #007AFF)
- **Sign Out Button**: Red text (`colors.destructive` #FF3B30), centered, at bottom
- **Cell Height**: Minimum 44px (iOS touch target standard)
- **Cell Padding**: Horizontal `spaceLg` (16px), vertical `spaceLg` (16px)
- **Section Spacing**: `space3xl` (32px) between sections

### Design System Reference
[Source: Story 6.1 Dev Notes, docs/todomorning-app-lovable-prompt.md]

**Colors:**
- Primary: #007AFF (Apple blue) - `colors.primary`
- Surface: #F2F2F7 (iOS grouped background) - `colors.surface`
- Background: #FFFFFF (white cells) - `colors.background`
- Text Primary: #000000 (black labels) - `colors.textPrimary`
- Text Secondary: #6E6E73 (gray secondary text) - `colors.textSecondary`
- Separator: #C6C6C8 (divider lines) - `colors.separator`
- Destructive: #FF3B30 (red) - `colors.destructive`

**Typography:**
- Caption: 13px / 1.3 / 400 (section headers) - `typography.caption`
- Body: 15px / 1.4 / 400 (cell text) - `typography.body`
- Body Large: 17px / 1.5 / 400 (navigation, buttons) - `typography.bodyLarge`
- Title Medium: 28px / 1.3 / 600 (screen title) - `typography.titleMedium`

**Spacing:**
- Space Lg: 16px (cell padding, icon-text gap)
- Space XL: 20px (section margins)
- Space 2XL: 24px (screen padding)
- Space 3XL: 32px (large vertical space, section spacing)
- Radius Sm: 8px (buttons)
- Radius Md: 12px (cards, inputs)

### Important Design Notes

**iOS Settings Pattern:**
- Grouped sections with white cells on gray background
- Section headers are small, uppercase, gray text above each group
- Cells have 1px separator lines between them (not above first or below last)
- Rounded corners on first and last cells of each group (optional, but common)
- Disclosure indicators (>) appear on right side of tappable rows
- Toggle switches appear on right side with proper spacing

**Touch Targets:**
- All interactive elements: Minimum 44x44 points (iOS standard)
- Rows should be tall enough to accommodate touch targets
- Disclosure indicators and switches should have adequate spacing

**Coordination with Story 3.1:**
- SettingsScreen was created in Story 3.1 with basic functionality
- This story adds design polish without changing functionality
- All existing features (time picker, save, test email) should remain functional
- Design updates should preserve all existing behavior
