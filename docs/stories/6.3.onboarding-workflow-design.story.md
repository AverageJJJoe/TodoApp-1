# Story 6.3: Onboarding & Workflow Screens Design

## Status
Approved

## Story
**As a** developer,  
**I want to** implement the onboarding flow and workflow mode selection with polished Lovable design,  
**so that** users have a delightful first-time experience that matches the app's visual quality

## Acceptance Criteria
1. Welcome screen (Epic 5, Story 5.1) matches Lovable Welcome design:
   - Large icon (🌙) with proper spacing and spring animation
   - Headline "Capture tonight, conquer tomorrow" (28px bold, `typography.titleMedium`)
   - Body text styling (17px, `typography.bodyLarge`)
   - Primary button styling (50px height, `colors.primary` background)
   - Page indicators (○ ○ ●) at bottom with proper styling
   - Skip button option (top-right, `text-text-tertiary`)
2. Delivery Time Picker (Epic 3, Story 3.1 enhancement or Epic 5) matches Lovable spec:
   - iOS-style time picker (wheel or native input via `@react-native-community/datetimepicker`)
   - Question text "When should we email your morning list?" (`typography.titleMedium` or appropriate size)
   - Tip text styling (13px gray, `typography.caption`, `colors.textSecondary`)
   - Proper spacing and layout matching design system
   - Time input: `h-[60px]` height, centered text, `text-4xl` font size, `bg-surface` background
3. Workflow Mode Selection (Epic 5, Story 5.1) matches Lovable spec:
   - Two mode cards (Fresh Start, Carry Over) with icons
   - Card styling: White background (`colors.card`), border (`colors.separator`), tap to select
   - Selected state: Blue border (`colors.primary`) + checkmark icon
   - Proper spacing between cards (`spacing.lg` or `spacing.xl`)
   - Mode descriptions clearly displayed
4. Onboarding navigation: Swipe gestures optional, back button on steps 2-3, "Skip" button option on step 1
5. All screens use design system tokens (`colors`, `typography`, `spacing`) and follow Lovable animation patterns (spring animations, smooth transitions)
6. Coordinate with Epic 5, Story 5.1 implementation (apply design as screens are built, or update after)

### Important Design Notes

**Onboarding Flow Pattern:**
- Step 1 (Welcome): Introduction, emoji, headline, body text, Continue button, Skip button
- Step 2 (Time Picker): Question, time picker, tip text, Continue button, Back button
- Step 3 (Mode Selection): Question, two mode cards, Continue button (disabled until selection), Back button
- After Step 3: Save preferences, navigate to MainScreen

**Animation Principles:**
- Spring animations for entrances (delightful, bouncy)
- Fade-in for text (staggered for visual interest)
- Smooth transitions between screens (slide, fade)
- Satisfying feedback on interactions (card selection, button press)
