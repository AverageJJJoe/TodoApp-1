**HTML Escaping:**
[Source: docs/architecture/email-delivery-system.md Lines 198-202]

Must escape HTML special characters to prevent XSS:
- Replace `<` with `&lt;`
- Replace `>` with `&gt;`
- Replace `&` with `&amp;`
- Replace `"` with `&quot;`
- Replace `'` with `&#39;`

Or use a simple escaping function:
```typescript
function escapeHTML(text: string): string {
  return text
    .replace(/&/g, '&amp;')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#39;')
}
```
