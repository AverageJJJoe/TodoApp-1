### Database Schema Context
[Source: docs/architecture/database-schema-data-model.md]

**Users Table Schema:**
The users table includes delivery preference fields:
- `delivery_time TIME NOT NULL DEFAULT '06:00:00'` - Time when user wants to receive daily email (24-hour format: HH:mm:ss)
- `timezone VARCHAR(50) NOT NULL DEFAULT 'UTC'` - User's timezone (e.g., 'America/New_York', 'UTC', 'Europe/London')

**UPDATE Pattern:**
[Source: docs/architecture/database-schema-data-model.md, Story 2.6 implementation]

For Story 3.1, we update user preferences:
- **Implementation**: `UPDATE users SET delivery_time = ?, timezone = ? WHERE id = ?`
- **Fields**: Only `delivery_time` and `timezone` are updated in this story
- **RLS Policy**: Users can only update their own record (enforced by Supabase RLS)

**Row-Level Security (RLS):**
[Source: docs/architecture/database-schema-data-model.md]

The users table has RLS enabled with UPDATE policy:
```sql
CREATE POLICY "users_update_own" ON users
  FOR UPDATE USING (auth.uid() = auth_id)
  WITH CHECK (auth.uid() = auth_id);
```

This means:
- Supabase automatically validates that the authenticated user can only update their own user record
- The query `supabase.from('users').update({ delivery_time, timezone }).eq('id', user_id)` will only succeed if the user_id matches the authenticated user
- Need to get user_id from users table first (query by auth_id) before UPDATE

**Supabase UPDATE Pattern:**
[Source: Story 2.6 implementation, docs/architecture/database-schema-data-model.md]

The Supabase query pattern for updating user preferences:
```typescript
// First, get user_id from users table
const session = useAuthStore.getState().session;
const { data: user, error: userError } = await supabase
  .from('users')
  .select('id')
  .eq('auth_id', session.user.id)
  .single();

if (userError || !user) {
  throw new Error('User not found');
}

// Then update user preferences
const { error } = await supabase
  .from('users')
  .update({ 
    delivery_time: '06:00:00',  // Format: HH:mm:ss
    timezone: 'America/New_York'
  })
  .eq('id', user.id);

if (error) {
  throw error;
}
```
