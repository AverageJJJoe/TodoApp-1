**1. Logo Size Clarification**
- **Issue:** Story notes that `assets/logo.png` is 120px × 120px (from Story 7.1), but app icon requires 1024×1024px
- **Impact:** Developer may need to resize or create new icon asset
- **Recommendation:** Clarify in Task 1 that logo will likely need resizing, or note that a 1024×1024px version should be created
- **Severity:** Low (Task 1 already addresses this, but could be more explicit)

**2. Splash Screen Size Clarification**
- **Issue:** Story mentions two options (Option A: reuse logo, Option B: create dedicated splash.png) but doesn't specify recommended approach
- **Impact:** Developer may choose suboptimal approach
- **Recommendation:** Recommend Option B (dedicated splash.png) for better control, or provide guidance on when to use each option
- **Severity:** Low (Both options work, but guidance would be helpful)
