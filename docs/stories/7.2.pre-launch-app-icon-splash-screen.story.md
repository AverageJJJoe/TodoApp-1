# Story 7.2: Pre-Launch - App Icon and Splash Screen Configuration

## Status
Draft

## Story
**As a** user  
**I want to** see a professional app icon and splash screen when launching TodoTomorrow  
**So that** the app appears polished and production-ready on my device

## Acceptance Criteria
1. App icon configured in `app.json` using TodoTomorrow logo from `assets/logo.png`
2. App icon displays correctly on iOS home screen (1024×1024px source, properly scaled)
3. App icon displays correctly on Android home screen (1024×1024px source, adaptive icon configured)
4. Splash screen configured with TodoTomorrow branding (logo centered on white background)
5. Splash screen displays correctly on both iOS and Android
6. Icon and splash screen assets properly sized and optimized for production builds

### Expo App Icon Requirements

**Icon Specifications:**
- **Format:** PNG with transparency (or solid background)
- **Size:** 1024×1024px (Expo generates all required sizes automatically)
- **Location:** Root `assets/` directory (standard Expo convention)
- **Naming:** `icon.png` (or reference existing `logo.png` if suitable)

**Expo Processing:**
- Expo automatically generates all required icon sizes for iOS and Android
- iOS: Generates @1x, @2x, @3x variants for different device resolutions
- Android: Generates mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi densities
- Android Adaptive Icon: Requires foreground image (icon) and background color

### Splash Screen Requirements

**Splash Screen Specifications:**
- **Format:** PNG
- **Recommended Sizes:**
  - iOS: 2732×2732px (or Expo will scale from smaller)
  - Android: 2048×2048px (or Expo will scale from smaller)
- **Background:** White (`#ffffff`) matching current config
- **Content:** TodoTomorrow logo centered
- **Location:** Root `assets/` directory

**Expo Processing:**
- Expo automatically generates splash screens for all device sizes
- Uses `resizeMode: "contain"` to ensure logo scales properly
- Background color fills entire screen
