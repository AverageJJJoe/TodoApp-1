## Story
**As a** first-time user,  
**I want to** choose between Fresh Start and Carry Over modes during onboarding,  
**So that** the app matches my workflow preferences

## Acceptance Criteria
1. After magic link authentication, show onboarding screen (3-step flow: Welcome, Delivery Time, Workflow Mode)
2. Step 3 shows two mode cards: "Fresh Start" (tasks reset daily) and "Carry Over" (tasks persist)
3. User can select one mode by tapping the card
4. Save workflow mode to database: `UPDATE users SET workflow_mode = ? WHERE id = ?` OR set during user creation
5. Navigate to MainScreen after mode selection is saved
6. *(Optional)* If user skips workflow mode selection (via Skip button), default to `'carry_over'` mode

### Database Schema Context
[Source: `docs/architecture/database-schema-data-model.md`, `supabase/migrations/001_users_table.sql`]

**Users Table - Workflow Mode Field:**
- `workflow_mode VARCHAR(20) NOT NULL DEFAULT 'fresh_start' CHECK (workflow_mode IN ('fresh_start', 'carry_over'))`
  - Database uses **underscore** format: `'fresh_start'`, `'carry_over'`
  - Default value: `'fresh_start'`
  - CHECK constraint ensures only valid values

**CRITICAL:** Component uses **hyphen** format (`'fresh-start'`, `'carry-over'`), but database requires **underscore** format (`'fresh_start'`, `'carry_over'`). Must convert in `handleCompleteStep3` function.
