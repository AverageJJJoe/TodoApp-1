# Story 8.6: PostHog Retention Tracking & Analytics Dashboard

## Status
Done

## Epic Context
**Epic 8: Sentry Crash Logging, PostHog Analytics & Loops Email Sequences - Post-Launch Enhancement**
This story is part of Epic 8, a post-launch epic focused on integrating Sentry for crash logging, PostHog for product analytics, and Loops for automated email sequences. This story configures PostHog retention analysis and creates a custom analytics dashboard to measure Week 1 retention (primary metric) and 30-day retention to understand user engagement.

**Dependencies:** Stories 8.2 (PostHog Setup) and 8.3 (PostHog Event Tracking) must be complete. PostHog must be initialized and events must be tracked before retention analysis can be configured.

## Story
**As a** product manager  
**I want** PostHog configured to track retention metrics  
**So that** I can measure Week 1 retention (7 days after signup) and 30-day retention to understand user engagement

## Acceptance Criteria
1. PostHog retention analysis configured with **PRIMARY FOCUS on Week 1 retention**:
   - **Week 1 retention cohort analysis** - Users who return 7 days after signup (PRIMARY METRIC)
   - **30-day retention cohort analysis** - Users who return 30 days after signup
   - Daily active users (DAU) tracking
   - Weekly active users (WAU) tracking
2. Custom PostHog dashboard created with key metrics:
   - **Week 1 retention rate** (prominently displayed)
   - **30-day retention rate**
   - Signups per day
   - Active users (DAU/WAU)
   - Task creation rate
   - Crash rate (from Sentry integration - Story 8.1)
3. PostHog insights configured for:
   - `week1_retention` - **PRIMARY METRIC**: Users who return after 7 days (calculated from `user_signed_up` event)
   - `day30_retention` - Users who return after 30 days
   - `task_creation_rate` - Average tasks per user per day
4. Dashboard shared with team (if applicable)
5. Weekly retention report automated (PostHog scheduled reports) - **Focus on Week 1 retention in reports**

### Previous Story Insights
[Source: docs/stories/8.3.posthog-event-tracking-implementation.story.md]

**Key Patterns from Story 8.3 (PostHog Event Tracking):**
1. **PostHog Event Tracking:** Events are tracked using `posthog-react-native` package
   - Helper functions in `src/lib/posthog.ts` for event tracking
   - Events tracked: `task_added`, `task_completed`, `task_deleted`, `email_sent`, `user_signed_up`, `user_logged_in`, `paywall_viewed`
   - User identification via `identifyUser()` function (links events to users)

2. **Event Properties:** Events include relevant properties:
   - `task_added`: `task_id`, `user_id`, `timestamp`, optional properties
   - `task_completed`: `task_id`, `user_id`, `timestamp`
   - `user_signed_up`: `user_id`, `email`, `cohort`
   - `email_sent`: `user_id`, `task_count`, `email_type` (from Edge Function)

3. **PostHog Integration Points:**
   - React Native app: Events tracked via `posthog-react-native` package
   - Edge Functions: Events tracked via PostHog HTTP API (`https://us.i.posthog.com/capture/`)
   - User identification: Set in `authStore.setSession()` when session established

4. **PostHog Configuration:**
   - API key: `EXPO_PUBLIC_POSTHOG_KEY` (from EAS secrets)
   - Host: `EXPO_PUBLIC_POSTHOG_HOST` (default: `https://us.i.posthog.com`)
   - Autocapture: Enabled for automatic event tracking
   - User identification: Configured via `identifyUser()` helper function

### Retention Analysis Approach
[Source: docs/prd/epic-8-posthog-loops-integration.md]

**Week 1 Retention (Primary Metric):**
- Cohort: Users who signed up (`user_signed_up` event)
- Return event: Any user action (e.g., `task_added`, `task_completed`, `user_logged_in`)
- Retention period: 7 days after signup
- Calculation: PostHog automatically calculates percentage of users who return within 7 days

**30-Day Retention:**
- Cohort: Users who signed up (`user_signed_up` event)
- Return event: Any user action
- Retention period: 30 days after signup
- Calculation: PostHog automatically calculates percentage of users who return within 30 days

**Active Users Tracking:**
- Daily Active Users (DAU): Count of unique users per day (any event)
- Weekly Active Users (WAU): Count of unique users per week (any event)
- Calculation: PostHog automatically calculates DAU/WAU based on event tracking
