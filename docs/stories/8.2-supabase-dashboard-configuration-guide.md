# Magic Link Email Template Configuration Guide

## Overview
This guide provides step-by-step instructions for configuring the TodoTomorrow-branded magic link email template in Supabase Dashboard.

## ⚠️ IMPORTANT: Configure BOTH Templates

Supabase uses **different email templates** depending on whether the user is new or existing:
- **"Confirm signup"** → Used for NEW users (first-time signup)
- **"Magic Link"** → Used for EXISTING users (returning sign-ins)

**You must configure BOTH templates** to ensure all emails show TodoTomorrow branding. See `8.2-EMAIL-TEMPLATE-FIX-GUIDE.md` for troubleshooting if emails still show Supabase branding.

## Prerequisites
- Access to Supabase Dashboard for your project
- Template HTML ready:
  - Magic Link: `8.2-magic-link-template-design.html`
  - Confirm signup: `8.2-confirm-signup-template-design.html`

## Configuration Steps

### Step 1: Navigate to Email Templates
1. Log in to [Supabase Dashboard](https://supabase.com/dashboard)
2. Select your project
3. Navigate to: **Authentication** → **Email Templates**
4. You should see a list of available templates:
   - **Confirm signup** ← Configure this FIRST (for new users)
   - Invite user
   - **Magic Link** ← Configure this SECOND (for existing users)
   - Change Email Address
   - Reset Password

### Step 2: Configure "Confirm signup" Template (For New Users)

1. Click on **"Confirm signup"** template
2. Update the **Subject** field to: `"Confirm your TodoTomorrow account"` or `"Welcome to TodoTomorrow"`
3. Copy the HTML from `docs/stories/8.2-confirm-signup-template-design.html`
4. Paste it into the **Body (HTML)** field
5. **Important:** Ensure `{{ .ConfirmationURL }}` is preserved exactly as shown (Go Templates syntax)
6. Click **Save**

### Step 3: Configure "Magic Link" Template (For Existing Users)

1. Click on **"Magic Link"** template
2. Update the **Subject** field to: `"Your TodoTomorrow Magic Link"` or `"Sign in to TodoTomorrow"`
3. Copy the HTML from `docs/stories/8.2-magic-link-template-design.html`
4. Paste it into the **Body (HTML)** field
5. **Important:** Ensure `{{ .ConfirmationURL }}` is preserved exactly as shown (Go Templates syntax)
6. Click **Save**

### Step 4: Verify Template Variables
Check that both templates include:
- `{{ .ConfirmationURL }}` - Used in the button link and fallback URL
- No other variables are required for basic functionality
- Optional: `{{ .Email }}` can be added for personalization if desired

### Step 5: Verify Configuration
1. Check that both templates show your custom HTML (not the default Supabase template)
2. Verify the subject lines are updated for both templates
3. Test with a NEW email address (will use "Confirm signup" template)
4. Test with an EXISTING email address (will use "Magic Link" template)

## Sender Name Configuration
**Note:** Sender name customization requires custom SMTP configuration:
- **Current:** "Supabase Auth" (`noreply@mail.app.supabase.io`) - Works fine for template customization
- **To change sender name:** Requires custom SMTP configuration with domain email (e.g., `hello@todotomorrow.com`)
- **Domain email setup:** Requires:
  - Email service provider (e.g., Resend, SendGrid, AWS SES)
  - Domain verification (SPF/DKIM records)
  - SMTP credentials
- **This story:** Template customization works with default SMTP - no domain email needed
- **Future story:** Custom SMTP configuration can be done later when domain email is set up (deferred per AC 1 note)

## Testing
After configuring BOTH templates:
1. **Test with NEW email address:**
   - Request a magic link with an email that doesn't exist in Supabase
   - Should receive "Confirm signup" email with TodoTomorrow branding
   - Verify subject line: "Confirm your TodoTomorrow account"
   
2. **Test with EXISTING email address:**
   - Request a magic link with an email that already exists
   - Should receive "Magic Link" email with TodoTomorrow branding
   - Verify subject line: "Your TodoTomorrow Magic Link" or "Sign in to TodoTomorrow"

3. **For both emails, verify:**
   - Email body matches design (TodoTomorrow branding)
   - Magic link button works correctly
   - Footer shows TodoTomorrow branding (no Supabase branding)
   - Authentication succeeds when clicking the link

## Troubleshooting

- **Still seeing Supabase branding?**
  - ⚠️ **Most common issue:** You need to configure BOTH templates ("Confirm signup" AND "Magic Link")
  - If you only configured "Magic Link", new users will still see Supabase branding
  - See `8.2-EMAIL-TEMPLATE-FIX-GUIDE.md` for detailed troubleshooting

- **Template not saving:** Check for HTML syntax errors
- **Variables not working:** Ensure Go Templates syntax is correct (`{{ .VariableName }}`)
- **Email not received:** Check Supabase SMTP configuration and rate limits
- **Button not clickable:** Verify `{{ .ConfirmationURL }}` is correctly placed in `<a href="">` tag
