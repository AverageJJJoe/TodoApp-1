# Story 7.8: Pre-Launch - App Review Prompting

## Status
Draft (Deferred - Post-Launch)

## Story
**As a** engaged user  
**I want to** be prompted to review the app at the right moment  
**So that** I can share my positive experience and help others discover the app

## Acceptance Criteria
1. Install `react-native-in-app-review` library
2. Track engagement metrics: app opens, tasks added, tasks completed, days since install
3. Implement "happiness engine" that calculates engagement score
4. Prompt eligibility: After 2-3 days of use, 3+ sessions, engagement score > threshold (e.g., 16 points)
5. Two-tap flow: Pre-screen ("Are you liking the app?") → Review prompt (if yes) or feedback form (if no)
6. Cooldown: 90 days between prompts, lifetime cap: 3 prompts max
7. Pre-screen uses fun, brand-aligned copy
8. Review prompt uses native platform APIs (iOS SKStoreReviewController, Android In-App Review API)

### Engagement Score Calculation

**Formula:**
```
score = (appOpens * 2) + (tasksAdded * 3) + (tasksCompleted * 2) - min(daysSinceInstall, 30)
```

**Example:**
- User has: 5 opens, 4 tasks added, 2 completed, 3 days since install
- Score = (5 * 2) + (4 * 3) + (2 * 2) - 3 = 10 + 12 + 4 - 3 = 23 points
- Threshold: 16 points → Eligible ✓

**Decay Logic:**
- Points decay by 1 per day after install
- Max decay: 30 days (after 30 days, no further decay)
- Prevents very old users from being prompted

### Prompt Eligibility Rules

**Timing:**
- Minimum 2 days since install
- Minimum 3 app opens (sessions)
- Engagement score >= 16 points

**Cooldown:**
- Last prompt >= 90 days ago (or never prompted)
- Lifetime prompt count < 3

**Platform Limits:**
- iOS: SKStoreReviewController limits to 3 prompts per year per app (platform handles this)
- Android: In-App Review API uses quotas (platform handles this)
- Our cooldown (90 days) ensures we don't hit platform limits

### Technical Constraints

**Engagement Tracking:**
- Must persist to AsyncStorage (survives app restarts)
- Must be lightweight (don't track every single interaction)
- Must respect user privacy (no PII in engagement data)

**Prompt Timing:**
- Must check eligibility on app open (after engagement updated)
- Must not interrupt critical user flows (don't prompt during onboarding)
- Must show prompt at natural break points (e.g., after task completion)

**Platform Compliance:**
- Must follow iOS App Store Review Guidelines (no review gating)
- Pre-screen is allowed (asking "Are you liking the app?" is fine)
- Cannot require review to unlock features (review gating is banned)
- Two-tap flow (pre-screen → review) is compliant
