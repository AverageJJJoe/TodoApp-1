### Supabase Edge Function Architecture
[Source: docs/architecture/email-delivery-system.md Section: Supabase Edge Function Implementation]

**Edge Function Structure:**
- Functions are written in TypeScript/Deno runtime
- Each function lives in `supabase/functions/{function-name}/` directory
- Main entry point: `index.ts` in function directory
- Functions use `Deno.serve()` handler pattern
- Functions can read environment variables via `Deno.env.get()`

**Edge Function Request/Response Pattern:**
[Source: Supabase Edge Functions documentation, architecture examples]

```typescript
Deno.serve(async (req: Request) => {
  // Parse request
  const { to, subject, html } = await req.json()
  
  // Process request
  // ...
  
  // Return response
  return new Response(JSON.stringify({ success: true }), {
    headers: { 'Content-Type': 'application/json' }
  })
})
```

**Environment Variables/Secrets:**
[Source: docs/architecture/deployment-strategy.md]

- Edge Functions use Supabase secrets management for API keys
- Secrets are configured via Supabase dashboard or CLI
- Access secrets in code: `Deno.env.get('SECRET_NAME')`
- Never commit secrets to code or version control

### Resend API Integration
[Updated: Pivoting from SendGrid to Resend for better MVP fit]

**Resend API Endpoint:**
- URL: `https://api.resend.com/emails`
- Method: `POST`
- Authentication: Bearer token in `Authorization` header
- Content-Type: `application/json`

**Resend Request Format:**
[Source: Resend API documentation]

```typescript
{
  from: 'hello@todotomorrow.com',
  to: [to],
  subject: subject,
  html: html
}
```

**Resend Response:**
- Success: HTTP 200 OK with JSON body containing `{ id: 'message-id', ... }`
- Message ID is in response body `id` field (not header)
- Error: HTTP 4xx/5xx with error details in JSON response body

**Resend Free Tier:**
- Free tier: 100 emails/day with unlimited total
- Covers MVP needs: ~500 users at 20% active = ~100 emails/day
- Better fit than SendGrid's time-limited trial-only free tier
- High deliverability out of the box (pristine IPs, no warm-up needed)

**Resend Configuration:**

**For MVP (Story 3.3):**
- Create free Resend account (forever free tier, not trial)
- Verify single sender email (can use temp email for MVP)
- Generate API key for Edge Function use
- No additional configuration needed for high deliverability

**Post-MVP (Future Enhancement):**
- Verify sender domain (DNS DKIM/SPF records) for better branding
- Set up webhooks for bounce/complaint handling (better than SendGrid for indie budgets)
