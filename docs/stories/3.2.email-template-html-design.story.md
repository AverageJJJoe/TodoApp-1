### Email Template Architecture Context
[Source: docs/architecture/email-delivery-system.md]

**Email Template Structure:**
The email template is a standalone HTML file that will be used by the Supabase Edge Function (Story 3.3) to generate email content. The Edge Function will read this template and replace placeholders with actual task data.

**Template Requirements from Architecture:**
- **Inline CSS Only:** Email clients have limited support for external stylesheets or `<style>` tags in `<head>`. All styles must be inline.
- **Responsive Design:** Template should work on mobile email clients (320px+ width)
- **No External Images:** Prevents spam flagging and improves deliverability
- **Plain HTML:** Simple, professional HTML without complex layouts
- **Font Stack:** Use system fonts: `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- **Color Palette:** 
  - Primary text: #333 (dark gray)
  - Secondary text: #666 (medium gray)
  - Tertiary text: #999 (light gray)
  - Background: #FFFFFF (white)
  - Borders: #eee (light gray)

**Template Placeholder Strategy:**
[Source: docs/architecture/email-delivery-system.md Section: Supabase Edge Function Implementation]

The architecture document shows the Edge Function will use template replacement. The template should use placeholders like:
- `{{tasks}}` - Where the task list HTML will be inserted
- Template will be read as a string and placeholders replaced with actual content

**Email Content Best Practices:**
[Source: docs/architecture/email-delivery-system.md Section: Email Deliverability Strategy]

- Plain, professional HTML with inline CSS
- No external images (prevents spam flagging)
- Simple text-only fallback
- Clear unsubscribe mechanism (header) - **Note:** MVP may defer unsubscribe to post-MVP
- No aggressive CTAs (keeps it simple)

## Testing

**Manual Test Steps:**
1. Create the template file at `supabase/functions/send-email/template.html`
2. Copy template to a test location (e.g., `test-template.html` in project root) for browser testing
3. Open test-template.html in Chrome browser
4. Verify template renders correctly:
   - Header "Good morning! ☀️" is visible
   - Placeholder `{{tasks}}` is visible and clearly marked
   - Footer text is visible
   - Layout looks clean and professional
5. Test responsive design:
   - Open Chrome DevTools (F12)
   - Toggle device toolbar (Ctrl+Shift+M)
   - Test at mobile widths: 320px (iPhone SE), 375px (iPhone 12), 414px (iPhone 12 Pro Max)
   - Verify text remains readable and layout doesn't break
6. Test with sample task data:
   - Manually replace `{{tasks}}` placeholder with:
     ```html
     <ul style="list-style: none; padding: 0; margin: 0;">
       <li style="padding: 8px 0; border-bottom: 1px solid #eee;">Sample task 1</li>
       <li style="padding: 8px 0; border-bottom: 1px solid #eee;">Sample task 2</li>
     </ul>
     ```
   - Verify task list renders correctly with proper spacing
7. Test in multiple email clients (optional but recommended):
   - Gmail (web)
   - Apple Mail (if available)
   - Outlook (web) - Note: Outlook has limited CSS support, test basic rendering

**Success Criteria:**
- Template file exists at correct location: `supabase/functions/send-email/template.html`
- Template includes header, task list placeholder (`{{tasks}}`), and footer
- Template renders correctly in browser at desktop and mobile widths
- Task list placeholder is clearly marked and positioned correctly
- Template uses inline CSS only
- Template follows email best practices (no external images, simple HTML)
- Template looks professional and clean
