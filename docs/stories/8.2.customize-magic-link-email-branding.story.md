### Supabase Email Template Customization

**Template Location:**
[Source: [Supabase Email Templates Documentation](https://supabase.com/docs/guides/auth/auth-email-templates)]
- **On hosted Supabase projects:** Edit templates in Supabase Dashboard → Authentication → Email Templates page
- **Template name:** "Magic Link" (one of the available templates: Confirm signup, Invite user, Magic Link, Change Email Address, Reset Password)
- Templates can be customized via web interface or Management API
- HTML templates support template variables using Go Templates syntax

**Available Template Variables:**
[Source: [Supabase Email Templates Documentation](https://supabase.com/docs/guides/auth/auth-email-templates)]
- `{{ .ConfirmationURL }}` - **PRIMARY:** Contains the confirmation URL (e.g., `https://project-ref.supabase.co/auth/v1/verify?token={{ .TokenHash }}&type=email&redirect_to=https://example.com/path`)
- `{{ .Token }}` - Contains a 6-digit One-Time-Password (OTP) that can be used instead of `{{ .ConfirmationURL }}`
- `{{ .TokenHash }}` - Contains a hashed version of `{{ .Token }}` - useful for constructing custom email links
- `{{ .SiteURL }}` - Contains your application's Site URL (configured in Authentication settings)
- `{{ .RedirectTo }}` - Contains the redirect URL passed when `signInWithOtp` is called (configured in Authentication settings)
- `{{ .Data }}` - Contains metadata from `auth.users.user_metadata` - use this to personalize the email message
- `{{ .Email }}` - Contains the original email address of the user
- **Note:** Supabase uses Go Templates syntax. All variables use `{{ .VariableName }}` format.

**SMTP Configuration:**
- **Current Setup:** Using Supabase default SMTP (`noreply@mail.app.supabase.io`)
- **Sender Name Customization:** Can be configured in Supabase Dashboard → Authentication → Email Templates (may require custom SMTP for full control)
- **Custom SMTP:** Required for custom sender email address (e.g., `hello@todotomorrow.com`)
  - Custom SMTP configuration: Supabase Dashboard → Project Settings → Auth → SMTP Settings
  - **Note:** For this story, focus on template customization. Custom SMTP configuration can be deferred if sender name can be changed via template settings.

**Template Customization Requirements:**
[Source: [Supabase Email Templates Documentation](https://supabase.com/docs/guides/auth/auth-email-templates)]
- HTML email templates must use inline CSS (email clients have limited support for external stylesheets)
- Table-based layouts recommended for email client compatibility
- Template variables use Go Templates syntax: `{{ .VariableName }}`
- Templates can be edited directly in Supabase Dashboard → Authentication → Email Templates
- **Go Templates support:** Can use conditional rendering (e.g., `{{ if eq .Data.Domain "example.com" }}...{{ end }}`)

**Important Limitations:**
- **Email prefetching:** Some email providers (e.g., Microsoft Defender) may prefetch links, consuming the token. Consider using `{{ .Token }}` OTP instead or custom redirect flow.
- **Email tracking:** External email providers with "email tracking" enabled may overwrite links. Disable tracking to ensure links work correctly.

**Magic Link Email Design Requirements:**

- Include "TodoTomorrow" branding in header (e.g., "Sign in to TodoTomorrow" or "Your TodoTomorrow Magic Link")

- Use same color scheme and typography as daily task emails
- **Example button style:** Use table-based button with inline CSS for email client compatibility:

**Note:** `{{ .ConfirmationURL }}` contains the full verification URL including token and redirect parameters. No need to construct the URL manually.

### Technical Constraints

**Email Client Compatibility:**
- Must use inline CSS (no `<style>` tags in `<head>`)
- Table-based layout for maximum compatibility
- No external images (prevents spam flagging)
- Simple HTML structure

**Template Variable Usage:**
[Source: [Supabase Email Templates Documentation](https://supabase.com/docs/guides/auth/auth-email-templates)]
- **Magic link URL:** `{{ .ConfirmationURL }}` - **CRITICAL:** Contains the full confirmation URL. Must be included in template as clickable button/link. Format: `https://project-ref.supabase.co/auth/v1/verify?token={{ .TokenHash }}&type=email&redirect_to=...`
- **Alternative:** `{{ .Token }}` - 6-digit OTP code (can be used instead of link for custom flow)
- **User email:** `{{ .Email }}` - User's email address (can be used for personalization)
- **Site URL:** `{{ .SiteURL }}` - Site URL from Supabase Authentication settings
- **Redirect URL:** `{{ .RedirectTo }}` - Redirect URL passed when `signInWithOtp` is called
- **User metadata:** `{{ .Data }}` - Access user metadata for personalization (e.g., `{{ .Data.Domain }}`)
- **Important:** All variables use Go Templates syntax: `{{ .VariableName }}`. Variables are case-sensitive.

**SMTP Configuration:**
- **Current:** Using Supabase default SMTP (`noreply@mail.app.supabase.io`)
- **Sender Name:** May be configurable in template settings. If not, custom SMTP required.
- **Custom SMTP:** Required for custom sender email address (e.g., `hello@todotomorrow.com`)
  - Configuration: Supabase Dashboard → Project Settings → Auth → SMTP Settings
  - **Note for this story:** Template customization can proceed independently. If sender name cannot be changed via template settings, document requirement for custom SMTP as future enhancement.
