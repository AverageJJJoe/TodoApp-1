### Keyboard Handling Best Practices
[Source: React Native KeyboardAvoidingView documentation]

**KeyboardAvoidingView Usage:**
- iOS: Use `behavior="padding"` - adds padding to push content up
- Android: Use `behavior="height"` - adjusts container height
- `keyboardVerticalOffset`: May need adjustment based on header/navigation bar height
- Wrap only the scrollable/form content, not the entire screen if using navigation headers

**Testing Considerations:**
- Test with different keyboard heights (different devices)
- Test with different input focus scenarios
- Verify layout restoration when keyboard dismisses
- Ensure no content is cut off or overlapping
