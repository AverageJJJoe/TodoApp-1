# Story 7.9: Pre-Launch - Share Extension (Share Sheet Integration)

## Status
In Progress (Partial Implementation)

## Story
**As a** user  
**I want to** share links or text from other apps (Safari, Chrome, etc.) directly to TodoTomorrow  
**So that** I can quickly add tasks from web pages, articles, or other content without manually copying and pasting

## Acceptance Criteria
1. TodoTomorrow appears in iOS Share Sheet when sharing URLs or text
2. TodoTomorrow appears in Android Share Menu when sharing URLs or text
3. Tapping TodoTomorrow in share sheet opens app (or brings to foreground)
4. Shared content (URL or text) is captured and displayed in task creation flow
5. User can edit shared content before creating task
6. Shared content creates new task with pre-filled text (URL or text content)
7. Share extension works from Safari, Chrome, Notes, and other common apps

### Component Specifications

**Share Handler Pattern:**
```typescript
// src/components/ShareHandler.tsx
import { useEffect } from 'react';
import ShareMenu from 'react-native-share-menu'; // or expo-share-intent

export const ShareHandler = ({ onShareReceived }) => {
  useEffect(() => {
    // Check for shared content on mount
    ShareMenu.getSharedText().then((sharedData) => {
      if (sharedData) {
        onShareReceived(sharedData);
      }
    });

    // Listen for share intents while app is running
    const listener = ShareMenu.addNewShareListener((sharedData) => {
      onShareReceived(sharedData);
    });

    return () => {
      listener.remove();
    };
  }, []);
};
```

**Shared Data Format:**
```typescript
interface SharedData {
  mimeType: string; // 'text/plain', 'text/html', 'text/url'
  data: string; // URL or text content
  extraData?: any; // Additional metadata
}
```

### iOS Share Extension Configuration

**Share Extension Setup:**
- Requires Xcode project modification
- Create Share Extension target
- Configure Info.plist with supported content types
- Set extension display name and icon

**Info.plist Configuration:**
```xml
<key>NSExtension</key>
<dict>
  <key>NSExtensionPointIdentifier</key>
  <string>com.apple.share-services</string>
  <key>NSExtensionAttributes</key>
  <dict>
    <key>NSExtensionActivationRule</key>
    <dict>
      <key>NSExtensionActivationSupportsWebURLWithMaxCount</key>
      <integer>1</integer>
      <key>NSExtensionActivationSupportsText</key>
      <true/>
    </dict>
  </dict>
</dict>
```

### Technical Constraints

**Platform Differences:**
- iOS: Requires Share Extension (app extension) - more complex setup
- Android: Uses intent filters - simpler setup
- Both platforms need native configuration

**Content Type Handling:**
- URLs: Extract URL string, display as-is
- Text: Extract text content, display as-is
- HTML: Strip HTML tags, extract text content
- Images: Not supported in MVP (text/URL only)

**App State Handling:**
- App closed: Share opens app, processes content
- App background: Share brings app to foreground, processes content
- App foreground: Share updates state, shows modal

**User Experience:**
- Pre-filled text should be editable
- User can cancel share (dismiss modal)
- After task created, clear shared content
- Don't auto-create task (user must confirm)
